# 雨云裸金属：区域、配置、带宽与计费怎么选，附官网套餐价格和 20 元试用说明

搜"雨云裸金属"的人通常带着两个问题来：这东西跟云服务器到底差在哪，以及现在什么价。这两个问题其实可以合成一个——你花同样的钱，能不能真的独占一整套硬件。

先说结论性的部分：雨云的裸金属物理机（官网叫 RBM，Rain Bare Metal）卖的是没有任何虚拟化层的物理服务器。你会拿到一台完整的机器，CPU、内存、硬盘、网卡都是自己的，可以进 BIOS、可以自己开虚拟化、可以装 Windows Server 也可以装 Rocky Linux。整个机房里那台机器只有你在用。

## 裸金属和云服务器差在哪里

云服务器是在一台物理机上用 KVM 之类做资源隔离，切出若干台虚拟机分给不同用户。好处是弹性——想加内存改个参数就行。代价是开销：虚拟化层本身要吃掉一部分性能，同宿主机上邻居的行为也可能影响你。

裸金属省掉的就是这一层。你能用到的性能更接近硬件真实水平，也不用担心隔壁那台被入侵或者被跑满 I/O 时自己被牵连。

雨云对这件事的处理方式值得单独说一下。传统的物理机租用，装系统得有人在机房插盘、配网络，改配置全靠工单。雨云用的是 PXE 自动化装机，下单后系统自动安装并激活，开机、关机、看屏幕都能在面板里完成，还支持 IPMI 硬重启——机器卡死了不用等客服。面板里能看到 CPU 温度、硬盘读写、硬盘健康状态、网络速率这些指标，用起来和云服务器的体验接近。

有个细节挺实用：每台机器在别人退租之后，会做一次硬件检查，避免把一块快挂的硬盘分给下一位用户。

顺便提醒一句防坑常识，这条是雨云自己在公告里说的——市面上有些商家把基于虚拟化的 VPS 换个名字叫"裸金属"卖。判断方法很简单：能不能装systemd以外的虚拟化软件、能不能看到真实硬件型号和硬盘健康信息、BIOS 能不能进。装不了的，就是穿了马甲的 VPS。

## 限流量和不限流量，同价怎么选

雨云裸金属的一个特殊设计是：同一台机器可以选"大带宽限流量型"或者"小带宽不限流量型"，两档价格一样。

具体差异是——大带宽款给高上行带宽，但有月流量额度；小带宽款带宽砍半，流量不限。限流量款的额度每月用不完可以累积到下个月，不清零。额度用完之后机器不会被停，只是限速到 5Mbps，想恢复高速就买流量包。流量包的价格按区域不同，宁波、十堰一带比较便宜，深圳要贵一些，下单前看一眼对应区域的价格表。

这个设计对两类人特别友好：跑游戏私服的，玩家在线有波动，用不完的流量能攒到假期高峰；做下载站或者图床的，平时流量不大，偶尔被转发到热帖时带宽能顶上去。

如果你不确定该选哪种，先看你的业务是"持续有稳定流量"还是"偶发高峰"。前者选不限流量省心，后者选大带宽限流量更划算。

## 什么人该买，买哪个区域

按业务类型给几条判断标准。

**Minecraft 或其他游戏服。** 单核性能是命门。宁波的 R7-8745HS 单核跑分在公开测评里能到 2000 分以上（Geekbench 6 单核），十堰的 i7-14700HX 经过特调超频，也是给这个场景准备的。玩家延迟要求高就选同区域的国内节点，玩家在海外就考虑香港。

**站点经常被打。** 十堰的 400G 到 800G 电信高防是雨云产品线里防御最厚的一档，宁波也能加到 400G 移动防御。这类防御是按 IP 计费的，一台机器只带一个普通 IP 时，想两头兼顾就得再加 IP。

**数据库和底层服务。** 这类负载吃的是内存容量和磁盘 I/O，虚拟化损耗小反而比跑分更重要。宁波和深圳的铂金、E5 v4 机型普遍配 64G 起，记忆里最大可以定制到 256GB。

**预算压得很死的个人项目。** 香港基础型 IIJ 390 元/月是这条产品线上比较少见的价格带，免备案、带宽也不小，代价是无额外防御可选，被打的时候只能自己扛。

**要不要买裸金属？** 如果你跑的只是博客、面板、轻量 API，云服务器更划算，弹性好、按天计费、出事能快速重建。裸金属的价值在"持续高负载 + 硬件独享"这个交叉点上，装机成本高、重建慢，用不满就是浪费。

## 常见问题

**裸金属能不能装 Windows？**
可以。官网列出的系统包括 Windows Server 2018/2022/2025 数据中心版，以及 Ubuntu 22.04/24.04、Debian 12、Rocky Linux 8/9 等，全自动安装并激活。

**能不能自己开虚拟机？**
因为是纯物理机，硬件虚拟化没有被屏蔽，你可以自己在这台机器上跑 KVM 或者 Docker 集群。

**IP 怎么加？**
默认带 1 个 IPv4，可以加购多个，普通 IP 和高防 IP 价格不同。香港普通直连 IP 5 元/月、高防 40 元/个，宁波 100G 高防 IP 30 元/个，十堰高防 IP 50 元/个。购买后还可以免费附加多个 IPv6 地址。

**流量用超了会被停机吗？**
不会。限速到 5Mbps，可以购买流量包恢复高速。额度每月自动叠加，次月不清零。

**后台能不能看到硬件状态？**
可以。面板提供 CPU、内存、网络速率、CPU 温度、硬盘读写和硬盘健康度等监控图表，另外支持 IPMI 级别的硬开关机。

**国内节点需要备案吗？**
宁波、十堰、深圳这些内地机房，用域名建站需要备案；香港和美国免备案。数据库、学习测试这类用途不受影响。

选型的思路其实不复杂：先定区域（决定延迟、备案和防御），再定计费模式（决定带宽和流量），最后看要不要定制。真正容易踩的坑是奔着最低价去买顶配机型，结果流量或者带宽成了瓶颈——先想清楚业务到底是吃 CPU、吃内存，还是吃带宽，钱花在哪里就不容易错。
